## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Writer** — A powerful text processor similar to Microsoft Word, allowing you to create, edit, and format text documents effortlessly.
- **Calc** — A spreadsheet application that provides advanced features, including chart functions and compatibility with Microsoft Excel.
- **Impress** — A presentation tool comparable to PowerPoint, capable of exporting presentations to SWF format and generating PDF files.
- **Base** — A database management program that enables you to create and manage databases and forms, equivalent to Microsoft Access.
- **Draw** — A graphical editor for creating flowcharts and diagrams, similar to Visio and CorelDRAW.
- **Math** — A tool for creating and editing mathematical formulas using a marker language.

### Advanced Features:
- **Custom Templates** — Start working immediately with included templates or create your own.
- **File Format Compatibility** — Open and save documents in various formats, including DOC, DOCX, PPTX, XLSX, and more.
